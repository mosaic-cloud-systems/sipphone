# Recents with redial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Recents tab on the dialer that lists this line's past calls, newest first, marks missed ones, and calls a row back with one tap.

**Architecture:** The SIP client gains two fields on its call state (direction, start time) and nothing else. `Phone.tsx` watches the call state return to idle and turns the last non-idle `CallInfo` into a `CallEntry` with pure helpers in `recents.ts`, which also own the text rules and the per-account `localStorage` persistence. `Dialer.tsx` gets a Keypad | Recents segmented control and renders a new presentational `Recents.tsx` list.

**Tech Stack:** React 18, TypeScript, Vite, Vitest (no DOM environment: pure helpers are unit-tested, components are checked by screenshot), SIP.js 0.21, plain CSS tokens in `src/styles.css`.

**Spec:** `docs/superpowers/specs/2026-10-29-recents-design.md` (mockup artboard "Dialer (Recents tab)" on the canvas linked there).

## Global Constraints

- Storage key per account: `sipphone.recents.<username>@<domain>`; chosen tab under `sipphone.dialerTab`. Every `localStorage` read and write is wrapped in try/catch; a blocked or corrupt store reads as an empty list.
- Never store the password or any login field with the history.
- Newest 100 entries are kept.
- Entry fields follow Wazo CDR names: `direction` (`inbound` | `outbound`), `name`, `start`, `answered`, `duration` (seconds).
- Copy, exactly: tab labels `Keypad` and `Recents`; header `Recent calls` (rendered uppercase by CSS); link `Clear`; empty state `No calls yet`; second-line words `Outgoing`, `Incoming`, `Missed`, `No answer`, separator ` · `; time `HH:MM` 24-hour, `Yesterday`, else `Mon D` with months `Jan Feb Mar Apr May Jun Jul Aug Sep Oct Nov Dec`.
- Colours only from existing tokens: `--emerald` (outgoing mark), `--graphite` on `--mist` (incoming mark), `--crimson` on `--crimson-tint` (missed), `--silver` header, `--accent` Clear link, `--slate` empty state.
- No SIP logic in components; `SipClient.ts` stays the only file importing SIP.js.
- Check each command's exit code on its own, never through a pipe.

## Review Focus

1. An outgoing call that fails before ringing (SIP.js rejects, `onCallHangup` right after `onCallCreated`): expect an "Outgoing · No answer" row, not a crash on a missing `answeredAt`. Pinned in Task 2.
2. A caller whose URI has no user part (`remoteUri` reads `undefined@host`): expect the row to show whatever `remote` holds, never the text "undefined". Pinned in Task 2.
3. A call across midnight: a call started at 23:50 yesterday is "Yesterday", one at 00:10 today is `00:10`; calendar days in local time, not 24-hour windows. Pinned in Task 3.
4. A corrupt or blocked store (non-JSON value, `localStorage` throwing): expect an empty list and no error. Pinned in Task 4.
5. Disconnecting while on a call: `stop()` resets the call to idle, so the entry must still be written with the duration up to that moment. Pinned in Task 6 by reasoning from the effect, verified by hand in Task 7.

### Task 2: Entries from call state

**Files:**
- Create: `src/components/recents.ts`
- Test: `src/components/recents.test.ts`

**Interfaces:**
- Consumes `CallInfo` from Task 1.
- Produces:
  - `interface CallEntry { id: string; direction: 'inbound' | 'outbound'; number: string; name?: string; start: number; answered: boolean; duration: number }`
  - `entryFor(call: CallInfo, endedAt: number): CallEntry | undefined` — `undefined` when `call.direction` or `call.startedAt` is missing (a call the state never saw start). `number` is the user part of `remoteUri` (text before `@`), falling back to `remote` when that part is empty or the literal `undefined`. `name` is `remote` only when `direction === 'inbound'` and `remote !== number`. `answered` is `answeredAt !== undefined`; `duration` is `floor((endedAt - answeredAt) / 1000)` else 0. `id` is `crypto.randomUUID()`.
  - `isMissed(entry: CallEntry): boolean` — inbound and not answered.
  - `addEntry(entries: CallEntry[], entry: CallEntry, cap = 100): CallEntry[]` — new array, entry first, trimmed to `cap`.
  - `unseenMissed(entries: CallEntry[], seenAt: number): number` — count of missed entries with `start > seenAt`.

### Task 3: Row text and time labels

**Files:**
- Modify: `src/components/recents.ts`
- Test: `src/components/recents.test.ts`

**Interfaces:**
- Consumes `CallEntry`, `isMissed` from Task 2, `formatDuration(ms)` from `duration.ts`.
- Produces:
  - `rowText(entry: CallEntry): { title: string; meta: string }` — `title` = `name ?? number`; `meta` joins with ` · `: the word (`Missed` when missed, else `Incoming`/`Outgoing`), then `number` only when `title` is the name, then `formatDuration(duration * 1000)` when answered, or `No answer` when outbound and not answered; a missed row has no third part.
  - `whenLabel(start: number, now: number): string` — `HH:MM` when same local calendar day as `now`, `Yesterday` when the previous calendar day, else `Mon D` from the fixed month list.
  - `ariaLabel(entry: CallEntry, now: number): string` — `Call <title>, <missed call|incoming call|outgoing call> <today at HH:MM | yesterday at HH:MM | on Mon D>` then `, <N minutes M seconds>` (singular forms when 1; omit minutes when 0) when answered, or `, not answered` when outbound and unanswered; nothing more when missed.

### Task 4: Per-account storage

**Files:**
- Modify: `src/components/recents.ts`
- Test: `src/components/recents.test.ts`

**Interfaces:**
- Produces:
  - `interface RecentsStore { entries: CallEntry[]; seenAt: number }`
  - `recentsKey(accountLabel: string): string` → `sipphone.recents.<accountLabel>`
  - `loadRecents(key: string): RecentsStore` — parses JSON; anything missing, malformed, or throwing yields `{ entries: [], seenAt: 0 }`; entries that are not objects with a string `number` are dropped.
  - `saveRecents(key: string, store: RecentsStore): void` — swallows storage errors.
  - `TAB_KEY = 'sipphone.dialerTab'`, `type DialerTab = 'keypad' | 'recents'`, `loadTab(): DialerTab` (default `keypad`), `saveTab(tab: DialerTab): void`.

- [ ] **Step 1: Write the failing tests** with a test-local fake installed on `globalThis.localStorage` in `beforeEach` (a `Map` behind `getItem/setItem/removeItem`), plus one case where `getItem` throws:

```ts
it('round-trips entries and the seen marker per account', () => {
  saveRecents(recentsKey('t1004@test.mosaicvoice.net'), { entries: [sample], seenAt: 42 });
  expect(loadRecents(recentsKey('t1004@test.mosaicvoice.net'))).toEqual({ entries: [sample], seenAt: 42 });
  expect(loadRecents(recentsKey('t1003@test.mosaicvoice.net'))).toEqual({ entries: [], seenAt: 0 });
});
it('reads a corrupt value as an empty list', () => {
  localStorage.setItem(recentsKey('a@b'), '{not json');
  expect(loadRecents(recentsKey('a@b'))).toEqual({ entries: [], seenAt: 0 });
  localStorage.setItem(recentsKey('a@b'), JSON.stringify({ entries: [{ bogus: 1 }, sample], seenAt: 'x' }));
  expect(loadRecents(recentsKey('a@b'))).toEqual({ entries: [sample], seenAt: 0 });
});
it('survives a blocked store', () => {
  // getItem/setItem throw
  expect(loadRecents('k')).toEqual({ entries: [], seenAt: 0 });
  expect(() => saveRecents('k', { entries: [], seenAt: 0 })).not.toThrow();
});
it('remembers the dialer tab', () => {
  expect(loadTab()).toBe('keypad'); saveTab('recents'); expect(loadTab()).toBe('recents');
  localStorage.setItem(TAB_KEY, 'nonsense'); expect(loadTab()).toBe('keypad');
});
```
